# Sistema de Gestión de Inventario y Ventas - Velas Estrella de David

## Descripción

Este proyecto consiste en el desarrollo de un sistema de gestión de inventario y ventas para la empresa **Velas Estrella de David**. La aplicación permitirá administrar productos, controlar existencias, registrar ventas y gestionar usuarios de manera eficiente, facilitando la organización de la información y mejorando los procesos operativos de la empresa.

## Objetivo

Desarrollar una solución tecnológica que permita automatizar el control de inventario y ventas, proporcionando un manejo seguro, rápido y confiable de la información.

## Funcionalidades Principales

- Gestión de productos.
- Control y actualización de inventario.
- Registro de ventas.
- Gestión de usuarios y roles.
- Consulta de historial de acciones.
- Generación de reportes de ventas e inventario.
- Alertas de stock bajo.

## Roles del Sistema

### Administrador
- Consultar productos.
- Gestionar inventario.
- Registrar ventas.
- Consultar reportes.
- Visualizar historial de acciones.

### Super Administrador
- Todas las funciones del Administrador.
- Crear, modificar y eliminar usuarios.
- Asignar roles.
- Gestionar productos.
- Acceder a todos los reportes del sistema.

## Tecnologías Utilizadas

- **Python**
- **FastAPI**
- **PostgreSQL**
- **Git y GitHub**
- **UML** para modelado del sistema

## Estructura General del Sistema

El sistema está compuesto por los siguientes módulos:

- Usuarios
- Productos
- Inventario
- Ventas
- Historial
- Reportes

## Beneficios

- Mejor control de inventario.
- Reducción de errores en registros manuales.
- Mayor seguridad en la gestión de información.
- Seguimiento de las actividades realizadas por los usuarios.
- Optimización del proceso de ventas.
